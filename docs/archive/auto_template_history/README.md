# Auto-Template History Archive

This directory keeps the phase-by-phase planning notes, pilot reports, curation
logs, and exploratory documents that were generated while building the current
`v1` auto-template release.

Use this archive when you need:

- detailed historical rationale
- exact phase sequencing
- earlier benchmark and tuning iterations
- provenance for design changes that no longer belong in the main reviewer path

Do not use this directory as the first entry point for merge review.

For the current canonical entry points, start from:

- `docs/briefing/README.md`
- `docs/maintainers/runtime_validation.md`
