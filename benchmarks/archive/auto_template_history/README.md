# Archived Benchmark Manifests

This directory keeps historical benchmark and tuning manifests that were useful
during auto-template development but are no longer the canonical entry points
for the release-oriented repository layout.

Typical contents:

- draft manifests
- promoted intermediate manifests
- exploratory tuning manifests
- future backend-comparison stubs

Current active benchmark entry points remain outside this archive:

- `benchmarks/auto_template_benchmark_manifest.yaml`
- `benchmarks/deployment_validation_manifest.sbml_lab_v1.yaml`
- `benchmarks/deployment_validation_manifest.template.yaml`
